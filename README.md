## 📐 Design & Engineering Details

- **Minimal Black & White**: Zero neon orbs, zero gradients, zero AI fluff. Clean Swiss-style editorial typography, matte black canvas, crisp white text, and subtle 1px gray borders.
- **Proportional 16:10 Fit**: Every website is rendered in a full 1280x800 desktop canvas and proportionally scaled down to fit the card's 16:10 aspect ratio without clipping, distortion, or horizontal scrolling.
- **Buttery Smooth Scrolling**: Default pointer events on embeds are locked to allow fast, frictionless scrolling down the page. Clicking "Interact" on any card unlocks live mouse navigation inside the embed.
- **Instant Search & Category Filtering**: Filter by category or search instantly across titles, tags, and URLs.
- **Zero Dependencies**: Pure HTML5, Vanilla CSS, and JavaScript.
